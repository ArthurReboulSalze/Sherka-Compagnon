# Artwork provenance

The transparent Sherka and Orion images were generated with the integrated image generation tool on October 10, 2026. Application icons derive from Sherka's image through Tauri's icon tool.

- `public/assets/sherka.png`: original retrofuturistic circular shipboard console, loosely inspired by 1980s space-adventure animation. No image from Ulysses 31 was downloaded or copied. The project is unaffiliated with the series.
- `public/assets/orion.png`: original celestial mechanical owl with navy and copper materials, luminous eyes and a constellation motif.
- `docs/images/sherka.png`: screenshot of the actual application using a fresh isolated demo profile, without personal conversations or memories.

Generated illustrations do not include cloned voices or private source images. Voice profiles and externally downloaded models are not distributed.
