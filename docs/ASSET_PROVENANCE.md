# Artwork provenance

The current companion image packs and golden orbital-star application logo were supplied by the project author for Sherka 0.8.0. The application logo is independent of the companion portraits; Windows executable and tray icons are derived from it with Tauri's icon tool.

- `public/branding/sherka-logo.png`: golden orbital-star application emblem. `docs/images/sherka-logo-gold.png` is an identical copy for the README with a distinct cache-safe filename.
- `public/assets/sherka.png` and `public/assets/sherka/`: the updated neutral portrait and six expressions for the retrofuturistic shipboard companion. The project is unaffiliated with Ulysses 31.
- `public/assets/botsy/`, `candis/`, `kit/` and `minerva/`: author-supplied neutral and emotion images for the four new starter companions.
- `docs/images/sherka-0.8.0.png`: screenshot of the actual 0.8.0 application using fresh isolated demo profiles, without personal conversations or memories.
- `docs/images/features-gold.svg`: repository-authored feature badges matching the golden application identity.

The original October 10 Sherka and Orion illustrations were generated with the integrated image tool. Orion is no longer distributed as a starter companion. Voice profiles, private conversations and downloaded models are not distributed.
