# Product specification

A local desktop companion for Windows (Debian port available) with an unobtrusive transparent avatar and optional control panel.

- Continuous listening after explicit microphone activation, natural turn detection and interruptible replies.
- Streamed text, prepared speech and safe cancellation.
- Independent personality, instructions, seven expression images, voice, provider, model, history, memory and optional persistent mood per character.
- Essential memories and selectively retrieved topical drawers, editable manually and through validated dialogue requests, with reviewed optimization and confirmed clearing.
- Loaded model context discovery, reply budgets and supported reasoning controls.
- VoiceStudio required for speech. Conversation through LM Studio, OpenAI-compatible or Anthropic APIs, or the Hermes remote agent, which keeps its own personality, memory and tools.
- Optional web search, image/text attachments, spontaneous conversation and ComfyUI conversation illustrations.
- AI-assisted character creation through ComfyUI: editable sheet, front-facing portrait, six emotions and transparency.
- Optional automatic startup of local VoiceStudio and ComfyUI, closing only what Sherka started; model switching and unloading on normal exit.
- Local SQLite storage and validated import/export (`.sherka.zip` packs), without bundled personal data or credentials.
- Manual signed updates for installed and directly launched Windows distributions.
- Visual changes respect reduced-motion preferences. Avatars use static expression images with crossfades; portrait or mouth animation is out of scope.

Technical contracts, limitations and planned work are documented separately.
