# Product specification

A local Windows desktop companion with an unobtrusive transparent avatar and optional control panel.

- Continuous listening after explicit microphone activation, natural turn detection and interruptible replies.
- Streamed text, prepared speech and safe cancellation.
- Independent personality, instructions, image, voice, model, history and memory per character.
- Essential memories and selectively retrieved topical drawers, editable manually and through validated dialogue requests.
- Loaded model context discovery, reply budgets and supported reasoning controls.
- VoiceStudio required for speech; LM Studio currently provides conversation.
- Automatic VoiceStudio startup, model switching and unloading on normal exit.
- Local SQLite storage and validated import/export, without bundled personal data.
- Manual signed updates for installed and directly launched distributions.
- Future animations, expressions and moods respecting reduced motion.

Technical contracts, limitations and planned work are documented separately.
