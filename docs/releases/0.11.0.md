# Sherka 0.11.0 — More imagination. Clearer memories.

Give your conversations the right picture, and your companion a memory you can shape. Sherka 0.11.0 brings SDXL scenes, editable negative prompts and memory optimization you review before applying.

- **Illustrious or SDXL:** choose the model family per companion. Sherka prepares tags for Illustrious or visual prose for SDXL, with your own negative prompt and LoRAs.
- **Your model collection:** browse every checkpoint exposed by ComfyUI and narrow the model/LoRA lists by folder. Register external directories in ComfyUI, then refresh Sherka's catalog.
- **A scene that fits the conversation:** landscapes and unrelated subjects can appear without the companion in front. When the companion belongs in the scene, its appearance description guides the image. Minerva's default description now explicitly calls for a robotic face.
- **Normal or Turbo:** disabling Turbo sets both samplers to 16 steps and doubles their original CFG — 3.8 and 7.0 in the supplied workflow.
- **Better support for small and thinking models:** more compatible scene-planning requests, clearer expression examples and a conservative expression fallback based on the visible answer.
- **Memories you control:** request optimization from Settings, Memory or `/optimize-memory`. Review the proposed shorter facts and notes, then confirm. Unchanged facts, source links and conversation history are preserved.
- **Clear with confirmation:** request `/clear`, then `/confirm-clear`, or use recognized localized phrases. Saved facts stay separate; confirmations expire after three minutes and are invalidated by a conversation or companion change.
- **Companions stay in sync:** selecting a character in the control panel also switches the desktop widget. All new interface controls are available in seven languages.

## Downloads and setup

- **Windows installer:** `Sherka-Compagnon_0.11.0_x64-setup.exe`.
- **Windows without installation:** extract `Sherka-Compagnon_0.11.0_windows-x64-portable.zip`, then run its executable.
- **Debian x64:** install `Sherka-Compagnon_0.11.0_linux-amd64.deb`; see the [Linux guide](https://github.com/ArthurReboulSalze/Sherka-Compagnon/blob/main/docs/LINUX.md).

Windows can check for this signed update from Settings. Linux package updates remain manual. VoiceStudio powers speech; connect LM Studio, a supported API provider or your Hermes server separately. ComfyUI and compatible checkpoints/LoRAs are optional, separate installations. Hermes keeps its own tools and memory and remains outside local image generation and expressions.

Profile/settings schema remains 8 and character export format remains 4. Keep installed and no-install copies aligned. Physical Linux audio and compositor behavior still need broader testing. Personal conversations, memories, recordings, private keys and external model weights are not included in the downloads.
