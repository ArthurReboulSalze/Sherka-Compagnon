# Sherka 0.7.0 — Give Hermes a voice

Connect your Hermes server, choose a profile, and talk through your desktop companion. Hermes keeps its personality, memory and tools; Sherka provides the avatar, microphone and VoiceStudio voice.

- Separate protected keys and persistent conversations for each server/profile.
- Streamed replies, interruption and explicit tool approvals.
- A Hermes-only **New conversation** widget button and `/new` shortcut.
- Setup guidance in seven languages, with a complete [connection guide](https://github.com/ArthurReboulSalze/Sherka-Compagnon/blob/v0.7.0/docs/HERMES.md).
- Hermes mode stays outside the future emotional-avatar system.

Also includes the conversation fixes prepared for 0.6.1: normal conversation continues when automatic web planning fails, replies default to 8,192 tokens, and unknown remote context limits use a configurable 64,000-token fallback.

VoiceStudio is required for voice. A configured Hermes HTTP API and a key for the selected profile are required for remote-agent mode.

## Choose your download

- **Installer:** `Sherka-Compagnon_0.7.0_x64-setup.exe`.
- **No installation:** extract `Sherka-Compagnon_0.7.0_windows-x64-portable.zip`, then run the executable inside.
- **Already using Sherka?** Open Settings and check for updates. Your profiles and memories stay in place.

Windows x64, WebView2 and the Visual C++ x64 runtime are required. VoiceStudio, speech models and your conversation provider are separate installations. See the [setup guide](https://github.com/ArthurReboulSalze/Sherka-Compagnon/blob/v0.7.0/docs/GETTING_STARTED.md).

Both editions include signed in-app update support. The direct executable, signatures, checksums and `latest.json` are also provided for the updater and verification.
