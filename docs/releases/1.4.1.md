# Sherka 1.4.1 — ask for a picture

- **Your companion knows its image generator.** It knows whether conversation illustrations are on or off, which model family is active (Illustrious or SDXL) and which checkpoint, so it no longer promises pictures that will not come or ignores the ones that do. It can say in a few words what it is about to draw, but never pretends to see the finished image.
- **Control it by voice.** Say "switch on the image generator", "switch it off" or "make me an image of…", in any of the seven interface languages. Only you switch it, with these words or the **Image** button; your companion never does it on its own and asks you to when it is off.
- **Your request waits for you.** Ask for a picture while the generator is off and it is kept; switch the generator on and it is drawn right away, even while ComfyUI is still starting. "Switch it on and make me…" does both in one message. Switching on alone starts the pictures with your next message.
- **A word when you press Image.** Turning the generator on with the button gets a short remark from your companion.

Also in this release:

- Sherka warms VoiceStudio up as soon as it is ready, so your first reply does not wait for its models to load. Nothing is played or saved.
- Sherka closes the VoiceStudio it started, and only that one, on every way out (quitting, updates, a crash), including its worker processes. A VoiceStudio you started yourself keeps running.
- When VoiceStudio refuses a request, for example after an update while a model or voice licence still waits to be accepted, Sherka tells you to open VoiceStudio instead of asking for an API key. Checked with VoiceStudio 0.5.7.

Illustrations stay unavailable in three-way conversations and for Hermes companions. Sherka never generates images during its own tests; the author checked the generator by voice in the Windows app.

## Downloads and setup

- **Windows x64 installer** — install normally or check **Settings → Updates** in Sherka.
- **Windows x64 portable ZIP** — extract the complete archive and run `sherka-compagnon.exe`.
- **Debian x64 package** — install the `.deb`; Linux updates remain manual.

Profiles, voices, conversations and memories stay in place; the database schema is unchanged (10). Automated checks passed on Windows and Linux, including the native Windows interface tests. On Debian 13, the released package starts with isolated data under a virtual display; physical Linux audio and desktop behavior still need broader testing. No personal conversations, saved memories or API keys are included in these downloads.
