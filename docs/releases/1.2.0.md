# Sherka 1.2 — a bigger view of your conversations

Double-click a conversation illustration to fill your screen while your companion stays in front, independently movable and resizable. Press Esc, double-click again or use the close button to return to the desktop image cell.

- **More room for scenes:** enlarge the image cell beyond its previous limit, with its placement still remembered per companion.
- **Finer character appearance:** add a negative appearance prompt beside the character's physical description. It applies only when the companion belongs in the scene, alongside your general negative prompt, for Illustrious and SDXL.
- **Images in the text cell:** paste images directly when the selected conversation model supports them. The placeholder now mentions image input.
- **Clearer first-image loading:** the generator explains that ComfyUI may need to start, then load the selected model and LoRAs before producing the first image.
- **A desktop freeze fixed:** activity notifications and geometry saving no longer hold engine locks while waiting for native window queries. The freeze was reproduced with 1.1.1, and the same regression passes with this fix.

New controls and messages are available in all seven interface languages. Existing companion settings default to an empty character negative prompt.

## Downloads and updates

- **Windows x64 installer** — install normally or check **Settings → Updates** in Sherka.
- **Windows x64 portable ZIP** — extract the complete archive and run `sherka-compagnon.exe`.
- **Debian x64 package** — install the `.deb`; Linux updates remain manual.

Native Windows checks cover full-screen stacking, avatar movement/resizing, image-cell restoration, clipboard images and the reproduced freeze. Debian compilation and focused core tests passed during development; physical Linux desktop/audio behavior still needs broader testing. No personal conversations, saved memories or API keys are included in these downloads.
