# Sherka 0.5.1

This update prevents an incompatible data folder from making Sherka close silently.

- A recovery screen explains the startup error and keeps signed GitHub updates available.
- Compatibility checks run before normal writes and migrations. Your profiles, conversations and memories are not reset.
- Recovery uses your saved interface language when readable and keeps conversation, microphone and model loading disabled.

Installed, no-install and development copies share user data by default. A newer copy can upgrade that data without updating an older executable. If a pre-0.5.1 copy cannot open, install this release over it or use the latest complete no-install ZIP.

Update from **Settings → Updates**, or download the Windows x64 installer or no-install ZIP below. VoiceStudio and LM Studio requirements are unchanged.
