# Sherka 0.5.0

A quieter desktop companion, with optional Internet search when you need it.

- **Controls that step out of the way.** Hover or click to reveal them. Leaving the widget, switching windows or opening the control panel dismisses them, including the companion picker. Keyboard access remains available.
- **An independent presence.** The README now shows the transparent desktop widget separately from the optional control panel.
- **DuckDuckGo search, without an account.** Enable on-request or automatic searches in Settings, with source links kept beside each answer. Search is off by default.
- **Fluid conversation continues.** Text streams as usual, searches can be cancelled, and spoken answers omit source numbers and URLs.
- **Seven languages.** Search controls, progress and failure notices follow your interface language.

Search queries go online; conversation and speech models stay local. This first version uses search snippets, not full web pages. DuckDuckGo can rate-limit or block requests, and small models can misattribute sources: check the linked pages for important facts.

Update from **Settings → Updates**, or download the **Windows x64 installer** or **no-install ZIP** below. VoiceStudio is required; LM Studio is currently the conversation provider. Models and voices are configured separately.

Profiles and memories stay in your Windows user folder. This release upgrades conversation history to store sources; after upgrading, do not open that data with an older version.
