# Sherka 1.3.2 — your images, your prompts

More control over how your companions look, from the first portrait to every conversation scene.

- **Start a character from your own picture.** In Character creation, choose **Start from an image**: it becomes the neutral portrait on the usual plain gray background, and your written idea becomes optional. If your connected model can see images, it also writes the physical description from the picture.
- **Edit the exact prompts.** Each portrait and emotion has a **Prompt** button showing the exact positive and negative text sent to ComfyUI. Your edit is sent as written and only that image needs regenerating; you can always go back to the automatic prompt.
- **Regenerate an existing companion's images.** On a companion's page, **Regenerate images** reopens its portrait and seven expressions in the studio, bundled companions included. Redo one emotion or the whole portrait, then apply the result: personality, voice, history and memories stay untouched.
- **Rewrite the current scene.** The pencil button on the desktop image cell opens the current scene prompt right below the image. Generate again with your own words; the edit is kept for variants and live mode until the next reply.
- **Tidier image settings.** Illustration settings are grouped into collapsible sections that remember their state. The LoRA folder filter and a new LoRA search sit right above your LoRAs, and the save button stays within reach.
- **Character creation** now sits right below **Companions** in the sidebar.

## Downloads and setup

- **Windows x64 installer** — install normally or check **Settings → Updates** in Sherka.
- **Windows x64 portable ZIP** — extract the complete archive and run `sherka-compagnon.exe`.
- **Debian x64 package** — install the `.deb`; Linux updates remain manual.

ComfyUI, its custom nodes and model weights remain separate installations; see the [ComfyUI guide](https://github.com/ArthurReboulSalze/Sherka-Compagnon/blob/main/docs/COMFYUI.md). Profiles, voices, conversations and memories stay in place; there is no data migration in this update. Automated Rust and native Windows tests passed with simulated ComfyUI and model services, and the image features were checked in the app by the user. Debian receives build and extracted-package startup checks; physical Linux audio and desktop behavior still need broader testing. No personal conversations, saved memories or API keys are included in these downloads.
