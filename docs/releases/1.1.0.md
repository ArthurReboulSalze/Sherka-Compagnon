# Sherka 1.1 — a companion that can start the conversation

Your companion can now break the silence, remember its own place on your desktop and share a simpler setup for voice and image services.

## What's new

- **Spontaneous conversation, at your pace.** Enable it per classic companion and choose a minimum/maximum idle delay. Sherka picks a random time for one short spoken invitation, then waits for a real reply. Typing, active conversation, voice pause and a hidden widget postpone it. Hermes profiles are excluded. Hosted providers can charge for these replies.
- **VoiceStudio without another window.** Sherka can start the prepared Python speech server in the background. Leave paths empty for automatic detection, or select your installation/runtime folder and Python. Open VoiceStudio once to install its engines and voices.
- **Set up shared services once.** VoiceStudio's connection and transcription model, microphone options, and VoiceStudio/ComfyUI local startup paths now belong in Settings. TTS engine, voice, language, speed and volume remain per companion.
- **One clear startup rule.** Each service has a single **Start with Sherka** option. A local service launched by Sherka closes with it, including its child processes. A server that was already running or is remote stays independent. ComfyUI starts only when the active classic companion has illustrations enabled; first images can take longer while it starts and loads models.
- **A desktop layout for every companion.** Avatar position/size and image-cell position/size are remembered when switching companions and after restarting. Illustrations stay behind the avatar when they overlap; text and controls remain accessible.
- **Companion packs stay portable.** Machine paths, shared speech settings and desktop positions stay on this device. Packs keep the character's voice references and preferences, with no conversations, memories, accumulated moods or API keys.

All new controls are available in the seven interface languages. VoiceStudio and ComfyUI still need their own installations and models; Sherka does not install them.

## Downloads and updates

- **Windows x64 installer** — for an installed copy and signed in-app updates.
- **Windows x64 no-install ZIP** — extract the complete archive and run `sherka-compagnon.exe`.
- **Debian x64 package** — install the `.deb`; Linux updates remain manual.

Existing Windows users can check **Settings → Updates**. The first launch migrates the active companion's VoiceStudio address and transcription choice into the shared settings. Each companion keeps its own voice. User data stays outside the application folder. Use the current version when reopening updated settings; older executables may show recovery mode.

Validation includes 144 Rust tests on Windows, 142 on Debian, native widget/service/restart scenarios, and a real headless VoiceStudio start/stop check. One optional public-search test was skipped on each platform. Physical Linux audio and compositor behavior still need broader testing.
