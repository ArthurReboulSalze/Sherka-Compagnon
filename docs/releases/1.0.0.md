# Sherka 1.0 — companions with a lasting mood

Your desktop companion can now carry a mood from one exchange to the next, wear your chosen interface theme and keep conversation illustrations flowing through ComfyUI.

## What's new

- **Persistent moods, when you want them.** Enable them per companion. Repeated reactions linger, ordinary exchanges gradually soften them, and a warmer tone can calm an angry character. Bounded points prevent every mood from building up indefinitely. Reset mood independently; conversation deletion can include it too. Hermes keeps its own behavior.
- **A coordinated desktop widget.** Buttons, menus and the text/image cells follow your control-panel theme. The active avatar halo retains the companion's own accent, with the existing gentle expression fades.
- **Live conversation illustrations.** Keep generating fresh variations of the latest exchange, showing only the newest image without a counter. Sherka interrupts its own image work for speech recognition, text and speech synthesis, then resumes. This requires ComfyUI 0.3.57 or newer; other clients' jobs are left alone.
- **Advanced ComfyUI control.** Choose output size (default 768 × 768), independent steps and CFG for both sampling passes, and a shared sampler. Advanced values survive Turbo changes. Export the active API workflow as a starting point for your own graph.
- **A catalog that remembers.** Select models and LoRAs immediately from the device's saved list. The prominent refresh button replaces the full catalog, reflecting additions, moves and removals; a failed scan keeps the old list usable.
- **Optional local ComfyUI startup.** Save your Python/portable installation folder and, if needed, its Python interpreter. With illustrations enabled, Sherka reuses a running server or starts it and waits for readiness. First images may take longer while ComfyUI and models load. Remote servers are never started locally, and ComfyUI stays running when Sherka exits.
- **More reliable everyday commands.** Improve reasoning-model web-search planning, add a search-connection test, recognize more conversation-clearing requests and keep saved facts separate. Forgetting a fact also covers pending extracted memories. Spoken replies remove emojis so the voice does not read them aloud.

All new controls are available in the seven interface languages. Conversations, memory, voice and images still depend on your selected services and models; Hermes remains outside local moods and ComfyUI illustration generation.

## Downloads and updates

- **Windows x64 installer** — recommended for an installed copy and signed in-app updates.
- **Windows x64 no-install ZIP** — extract the complete archive and run `sherka-compagnon.exe`.
- **Debian x64 package** — install the `.deb`; Linux updates remain manual.

Existing Windows users can check **Settings → Updates**. Installed and no-install copies share the same user data folder. This release upgrades companion databases to schema 9; back up before upgrading and avoid reopening them with older executables. Persistent moods are off by default. Companion packs carry the preference, never accumulated mood points; messages, memories and API keys are excluded too.

VoiceStudio and conversation models/providers are configured separately. ComfyUI is optional and is not installed by Sherka. No personal conversations, saved memories, API keys or model weights are bundled. Linux has compilation and headless startup coverage; physical Linux audio/desktop validation remains limited.
