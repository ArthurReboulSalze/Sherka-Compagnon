# Sherka 0.6.0

Choose the intelligence behind each companion: keep LM Studio local, connect OpenRouter or Z.ai (API credit or Coding Plan), or use OpenAI, Anthropic and compatible APIs.

- Provider, model, voice, context and thinking preferences stay with each companion.
- Windows protects API keys; exported profiles never include them.
- OpenAI Chat Completions and Anthropic Messages stream final text into the existing voice pipeline.
- Context and output limits are respected when advertised; missing context limits require an explicit ceiling.
- Switching to a remote provider unloads the managed LM Studio model without loading a remote model into local VRAM.

VoiceStudio remains required for voice. Remote providers receive conversation context and recalled memories, and their API fees and privacy policies apply. LM Studio remains the default for offline conversations.

See [provider setup](https://github.com/ArthurReboulSalze/Sherka-Compagnon/blob/main/docs/PROVIDERS.md). Update from **Settings → Updates** or use the Windows installer or no-install ZIP.
