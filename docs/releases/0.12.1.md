# Sherka 0.12.1 — images that follow your scene

Ask for a new outfit, a dance or a different setting: the illustration planner now gives your visual request priority over the companion's reply and its usual pose or clothing.

- **Your scene comes first:** action, outfit, pose, expression and setting guide both Illustrious and SDXL prompts. The companion's visual identity remains a reference, rather than a fixed costume.
- **Fewer accidental doubles:** the planner resolves character count and a short scene description before writing the image prompt. A single companion is requested by default; “you and me together” calls for distinct subjects. Illustrious's `solo` tag follows the planned composition.
- **Complete SDXL descriptions:** full sentences reach ComfyUI without the old short-tag cutoff removing clothing, actions or scenery.
- **Natural requests:** examples and synthetic checks cover all seven interface languages; no special command or exact trigger phrase is required.

Image composition and likeness still depend on the language model, checkpoint and LoRAs. These changes improve prompt preparation; they do not guarantee every generated detail. Avatar expressions remain separate from conversation illustrations, and Hermes keeps its own tools.

## Downloads

- **Windows x64 installer** — recommended for an installed copy and signed in-app updates.
- **Windows x64 no-install ZIP** — extract and run `sherka-compagnon.exe`; it shares the installed copy's user data folder.
- **Debian x64 package** — install the `.deb`; Linux updates remain manual.

VoiceStudio and conversation models/providers are configured separately. ComfyUI is optional. No conversations, saved memories or API keys are included. Linux has build and headless startup coverage; physical Linux audio/desktop validation remains limited.
