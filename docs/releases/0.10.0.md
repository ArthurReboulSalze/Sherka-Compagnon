# Sherka 0.10.0 — Give your conversations a picture

Your companion now brings words, voice and illustrated scenes together on the desktop. This release also introduces a Debian x64 package alongside the Windows installer and no-install edition.

- **Conversation illustrations:** connect ComfyUI and an Illustrious checkpoint, with per-character appearance, LoRAs and strengths. An optional Turbo mode applies the supplied acceleration LoRA automatically.
- **Pictures while you talk:** scene preparation starts as soon as the reply text finishes. Generate 1–8 variations, move or resize the image cell, and loop them with configurable timing and soft crossfades. Hermes remains outside local image generation.
- **Text at your fingertips:** a transparent input follows the avatar. Type, paste or drop text, and attach images with compatible vision models. Resizing immediately adjusts the widget surface; refreshes retain the chosen text height.
- **Make it yours:** six interface themes, a halo in the companion's own color, and controls that stay close to the visible avatar, including wide characters such as Kit.
- **Smoother speech input:** preserve confirmed segments and resumed speech, filter targeted subtitle-credit noise, and shorten widget error notices above the controls.
- **More search choices:** DuckDuckGo without an account, optional Brave/Tavily API keys, or your SearXNG instance. Preferences stay per companion; API keys stay in the OS vault.
- **Linux begins here:** a native Debian x64 package, Secret Service credentials and manual updates. Voice/model applications remain separate and are not bundled or installed by Sherka. Physical Linux audio and compositor behavior still need broader testing.

## Downloads and setup

- **Windows installer:** `Sherka-Compagnon_0.10.0_x64-setup.exe`.
- **Windows without installation:** extract `Sherka-Compagnon_0.10.0_windows-x64-portable.zip`, then run its executable.
- **Debian x64:** install `Sherka-Compagnon_0.10.0_linux-amd64.deb`; see the [Linux guide](https://github.com/ArthurReboulSalze/Sherka-Compagnon/blob/main/docs/LINUX.md).

Windows updates remain available from Settings, with signed installer and direct-executable downloads. Linux updates are manual. VoiceStudio is required for speech; configure LM Studio, a supported API provider or Hermes separately. ComfyUI and compatible models/LoRAs are optional, separate installations.

Profiles upgrade to schema 8; character exports use format 4 and accept older formats. Keep installed and no-install versions aligned. Conversation history, memories, recordings, private keys and external LLM/STT/TTS/diffusion weights are not included in these downloads.
