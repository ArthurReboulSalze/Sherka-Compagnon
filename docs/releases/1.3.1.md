# Sherka 1.3.1 — snappier voice conversations

This update focuses on how quickly and smoothly your companion answers out loud.

- **The voice starts sooner.** The first spoken phrase is now short — it can end at a natural comma — and following phrases grow while the first one plays, so there is no gap after the opening sentence.
- **Smoother interruptions.** When you talk over your companion, its voice fades out over 30 milliseconds instead of cutting mid-sound, removing the small click.
- **Fewer delayed turn endings.** A breath, click or lip noise after your last word no longer restarts the end-of-sentence wait.
- **Long replies are no longer cut after three minutes.** A streamed reply now stops only if the model stays silent for three minutes.
- **Lighter streaming.** Text reaches the control panel and widget in small batches instead of one update per word, and provider connections stay open between turns.
- **See where the time goes.** Each reply adds one line of timings (no conversation text) to the local audio diagnostics log. The [user guide](https://github.com/ArthurReboulSalze/Sherka-Compagnon/blob/main/docs/USER_GUIDE.md#measure-response-times) shows how to read it.

**Tip for the fastest voice chat:** a streaming speech-recognition engine (rather than Whisper, which transcribes only after you stop) and model thinking switched off for voice companions typically save several seconds per turn.

## Downloads and setup

- **Windows x64 installer** — install normally or check **Settings → Updates** in Sherka.
- **Windows x64 portable ZIP** — extract the complete archive and run `sherka-compagnon.exe`.
- **Debian x64 package** — install the `.deb`; Linux updates remain manual.

Profiles, voices, conversations and memories stay in place; there is no data migration in this update. Automated Rust and native Windows tests passed; Debian receives build and extracted-package startup checks, and physical Linux audio and desktop behavior still need broader testing. No personal conversations, saved memories or API keys are included in these downloads.
