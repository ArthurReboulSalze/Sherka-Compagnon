# Sherka 1.3.4 — lighter companions, same pictures

- **Smaller downloads.** The bundled companions now ship as lossless WebP images. Their artwork goes from 49.8 MB to 31.9 MB and the Windows executable from 99 MB to 83 MB, with every visible pixel unchanged.
- **Lighter custom companions.** Images from character creation, retouching, your own picture and avatar editing are stored as lossless WebP. They take less space than PNG and keep exactly the same quality, transparency included. Companions you already created stay as they are.
- **Nothing changes for sharing and generation.** ComfyUI and vision models still receive PNG, and `.sherka.zip` archives still contain PNG files, so companions exported from 1.3.4 import into earlier versions.

## Downloads and setup

- **Windows x64 installer** — install normally or check **Settings → Updates** in Sherka.
- **Windows x64 portable ZIP** — extract the complete archive and run `sherka-compagnon.exe`.
- **Debian x64 package** — install the `.deb`; Linux updates remain manual.

Profiles, voices, conversations and memories stay in place; the database schema is unchanged and existing images are not converted. Automated checks passed on Windows and Linux, including the native Windows interface tests, and the author checked companion display, character creation, picture import and archives in the Windows app. No personal conversations, saved memories or API keys are included in these downloads.
