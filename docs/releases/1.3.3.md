# Sherka 1.3.3 — let your companion finish

- **Muting the microphone no longer cuts the reply.** Turn your microphone off while your companion is talking and it finishes what it was saying. The microphone closes as soon as the reply is over. **Stop** and **Pause all voice activity** still interrupt immediately.
- **A cleaner Hermes companion.** The large stop button drawn over the Hermes avatar is gone. Use the small stop button in the widget toolbar (shown on hover) or type `/stop`.

## Downloads and setup

- **Windows x64 installer** — install normally or check **Settings → Updates** in Sherka.
- **Windows x64 portable ZIP** — extract the complete archive and run `sherka-compagnon.exe`.
- **Debian x64 package** — install the `.deb`; Linux updates remain manual.

Profiles, voices, conversations and memories stay in place; there is no data migration in this update. Automated checks passed and both changes were confirmed in the app. Debian receives build and extracted-package startup checks; physical Linux audio and desktop behavior still need broader testing. No personal conversations, saved memories or API keys are included in these downloads.
