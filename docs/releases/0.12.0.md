# Sherka 0.12.0 — companions to make your own and share

Keep your favorite companion close, give its images your own style, and share the complete character in one file.

- **Companions first:** the control panel now starts with Companions, followed by Conversation, Memory & history, and Settings.
- **Make a copy:** a more visible Duplicate action keeps personality, voice/model choices, illustration settings and expression images, with an empty history and memory.
- **Share a complete companion:** `.sherka.zip` packs contain a documented JSON manifest and all seven PNG expressions, including bundled artwork. Import creates a fresh companion. Conversations, memories and API keys stay out of the pack; legacy JSON profiles still import.
- **Your own positive prompt:** append your style, lighting or composition preferences to every generated ComfyUI scene, without model rewriting. Works with Illustrious tags and SDXL descriptions alongside the editable negative prompt.
- **A clearer introduction:** the README showcases the independent desktop widget, natural voice interruption and resumed speech, persistent memory, web search, file/image drops and local model choices.

## Downloads

- **Windows x64 installer** — recommended for an installed copy and signed in-app updates.
- **Windows x64 no-install ZIP** — extract and run `sherka-compagnon.exe`; it shares the installed copy's user data folder.
- **Debian x64 package** — install the `.deb`; Linux updates remain manual.

VoiceStudio and conversation models/providers are configured separately. ComfyUI is optional. Companion packs carry model/voice references and service addresses, not model weights or voice files; check them before sharing and after import. Linux has build and headless startup coverage; physical Linux audio/desktop validation remains limited.
