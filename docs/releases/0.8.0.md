# Sherka 0.8.0 — More personality, more expression

Meet **Botsy, Candis, Kit and Minerva**, joining Sherka on your desktop. Each brings a distinct personality and seven matching expressions, with a smooth half-second fade between images.

- **Make each character yours:** choose images and a VoiceStudio voice in **Avatar & voice**. Provider, model, reasoning, speech and Internet search settings now live together in **Companions**.
- **Seven expressions:** neutral, joy, sadness, anger, surprise, reflection and tenderness. The reply's tone selects an image; missing expressions fall back to neutral. No extra model request is needed.
- **A clearer identity:** a new orbital-star application logo, separate from your companion's portrait.
- **Stay in control of Hermes:** a visible **/stop** button and typed shortcut stop the current task, with server confirmation and retry if needed. The server stays running. Hermes continues to use its own tools and memory, with a neutral avatar.

Kit keeps his dry humor; Minerva is deliberately irritable and sharp-tongued. The four new personalities are localized at creation in the chosen interface language. Choose their models and voices yourself. Orion is no longer included as a starter example; existing personal profiles are preserved.

## Choose your download

- **Installer:** `Sherka-Compagnon_0.8.0_x64-setup.exe`.
- **No installation:** extract `Sherka-Compagnon_0.8.0_windows-x64-portable.zip`, then launch the executable inside.
- **Already using Sherka?** Open **Settings → Check for updates** to install this signed update.

Windows x64, WebView2 and the Visual C++ x64 runtime are required. VoiceStudio, models and voices are installed separately. See the [setup guide](https://github.com/ArthurReboulSalze/Sherka-Compagnon/blob/v0.8.0/docs/GETTING_STARTED.md).

Profiles upgrade automatically for expression images. Installed and no-install copies share the same Windows user data: keep them on 0.8.0 or later after upgrading. Existing conversations, memories and personal voice choices remain local. Deleted starter characters are not recreated on restart.

ComfyUI generation and speaking animations remain future work. Model expression choices and real microphone recognition still depend on your selected models and hardware. The system's reduced-motion preference disables image fades.

The direct executable, update signatures, `latest.json` and checksums are also attached for updates and verification.
