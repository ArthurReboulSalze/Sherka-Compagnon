Meet Sherka: a desktop companion with its own voice, personality and memories — powered by local AI.

Talk naturally, interrupt a reply and continue. Text streams as it is generated; upcoming speech is prepared during playback. Keep a transparent companion on your desktop and open the control panel when needed.

This first public release includes independent characters, editable memories, context budgeting, automatic VoiceStudio startup and a Settings button for signed GitHub updates.

### Downloads

- **Installer:** `Sherka-Compagnon_0.3.3_x64-setup.exe`.
- **No installation:** extract `Sherka-Compagnon_0.3.3_windows-x64-portable.zip` and run `sherka-compagnon.exe`.

**Requires Windows x64, WebView2, the Visual C++ x64 runtime, VoiceStudio and LM Studio**, installed separately with your own models and voices. LM Studio is the only conversation provider for now. The UI is in French; documentation is in English. Headphones are recommended for voice interruption.

User conversations, voices, memories and API keys are not included. Both distributions store data in your Windows user folder. Executables have signed updater artifacts but no Windows Authenticode certificate, so SmartScreen may show a prompt.

Next: avatar customization, speaking/listening animations, expressions and moods. See the [roadmap](https://github.com/ArthurReboulSalze/Sherka-Compagnon/blob/main/docs/ROADMAP.md).
