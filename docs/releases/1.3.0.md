# Sherka 1.3 — bring your own companion to life

Start with an idea and create a companion with its own personality, portrait and seven expressions. The new **Character creation** studio guides you from an editable character sheet to a transparent desktop avatar.

1. **Shape the character.** A connected companion's LLM proposes its name, personality and visual description. Edit the sheet freely; existing conversations and memories are not used.
2. **Approve the portrait.** ComfyUI renders a front-facing head-and-bust portrait with SDXL or Illustrious on a solid gray background.
3. **Create the emotions.** Flux Klein 4B edits the approved portrait. Generate or retry expressions individually, with large previews for checking the result.
4. **Apply transparency and add the companion.** Automatic background removal prepares the seven cutouts. The new companion starts with an empty history and memory; choose its own VoiceStudio voice afterwards.

Choose the models; the three creation workflows keep fixed, quality-focused settings. Selected models and catalog lists are remembered. Retrying an emotion preserves the other finished images.

## Also in this release

- **More control over conversation scenes:** optional IP-Adapter guidance from the companion's neutral portrait, recommended aspect ratios, explicit latent scaling and selectable final ×2 upscaling.
- **Shared web-search settings:** configure the provider and API keys once in Settings. Each companion keeps its own Internet access choice; Hermes keeps its own tools.
- **Help & about:** concise ComfyUI model/node requirements, audio guidance and privacy information inside the app.
- New controls and messages in all seven interface languages.

## Downloads and setup

- **Windows x64 installer** — install normally or check **Settings → Updates** in Sherka.
- **Windows x64 portable ZIP** — extract the complete archive and run `sherka-compagnon.exe`.
- **Debian x64 package** — install the `.deb`; Linux updates remain manual.

ComfyUI, its custom nodes and model weights are separate installations. Creation requires the portrait-workflow nodes, Flux Klein 4B with its compatible text encoder and VAE, and ComfyUI-RMBG with RMBG-2.0. See the [creation setup guide](https://github.com/ArthurReboulSalze/Sherka-Compagnon/blob/main/docs/COMFYUI.md#character-creation). VoiceStudio supplies the voice independently.

The complete creation flow was tested in the Windows app and confirmed end to end by the user. Live ComfyUI checks covered portrait rendering, Klein editing and usable alpha. Appearance and expression fidelity depend on the selected models and still benefit from visual review. Debian receives build and extracted-package startup checks; physical Linux audio and desktop behavior need broader testing. No personal conversations, saved memories or API keys are included in these downloads.
