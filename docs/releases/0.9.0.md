# Sherka 0.9.0 — A fresh conversation, the memories you choose

Start fresh with any companion. **Clear conversation** removes local messages, archive search results, quotations and summaries while keeping the facts you explicitly saved or approved. You can also say **“Clear our conversation”** or type **`/clear`**. Individual facts can be deleted from Memory, and an optional checkbox clears saved facts too.

Long spoken replies are more resilient: temporary capture congestion no longer shuts down playback or microphone consent. Interrupted transcription recovers for the next utterance, and headphone mode avoids unnecessary echo-reference work. Small local technical logs help diagnose future interruptions without storing conversation content or recordings.

For Hermes, the panel clears Sherka’s local history and starts a fresh client conversation. Server-side conversations and memory remain managed by Hermes.

## Windows downloads

- **Installer:** `Sherka-Compagnon_0.9.0_x64-setup.exe`
- **No installation:** `Sherka-Compagnon_0.9.0_windows-x64-portable.zip`

Existing installations can use **Settings → Check for updates**. Both editions use the same per-user data folder. Updating itself does not erase conversations or memories; deletion requires an explicit action.

VoiceStudio remains required for speech. Configure its models and voices separately, then select LM Studio, a supported API provider or Hermes for conversation.
